# Чартын стандарт (CH)

> 2026-10-28 хэрэглэгчийн гомдол: «Ганц чартыг харуулах гэж бүтэн дэлгэж эзлээд… бүх
> датасэт бүр рүү орж харж тулгаад чартын стандарт гаргаад мөрдөж сайжруул.»
> Үзлэгийн «Сарын үзлэг» 10 баганатай график 1240×430px болж, тэнхлэгийн 10px шошго
> 16.5px болсон байв.

## Яагаад ийм болж байв

Декарт график бүр `<svg viewBox="0 0 720 250" style="width:100%;height:auto">` хэлбэртэй
байв. Ийм svg картынхаа өргөнөөр **харьцаагаар** томордог тул:

| Картын өргөн | Графикийн өндөр | 10px шошго |
|---|---|---|
| 1240px (бүтэн өргөн) | 430px | 17px |
| 600px (хос мөр) | 208px | 8.3px |
| 340px (гар утас) | 118px | 4.7px — уншигдахгүй |

Үүнээс гадна тэнхлэгийг `max/2`, `max/4`-өөр хуваадаг байсан тул «15,710 · 31,420»,
«1.3M · 2.5M · 3.8M» (жинхэнэ алхам 1.25M) гэх мэт тойм биш, заримдаа худал шошго гарч
байв.

## Шийдэл — `js/erthub-chartkit.js` (`EHChartKit`)

Datawrapper, FT, Stripe-ийн dashboard-ын хэвшил:

1. **Plot тогтмол өндөртэй.** `.eh-ch-s` 138px · `.eh-ch-m` 196px · `.eh-ch-l` 232px
   (≤1100px: L 210; ≤640px: 124 / 164 / 184). Өргөн нь картаа дүүргэнэ.
2. **svg = зөвхөн plot.** viewBox нь plot тэгш өнцөгт, `preserveAspectRatio="none"` —
   багана/шугам сунана; шугамын зузаан `vector-effect="non-scaling-stroke"`-оор хэвээр.
3. **Бүх текст ба цэг HTML давхарга дээр**, хувиар байрлана: тэнхлэг, утгын шошго,
   легенд, цэг. Үсэг ҮРГЭЛЖ 10.5px (гар утсанд 10px), дугуй цэг зууван болохгүй.
4. **Тэнхлэг «гоё» алхмаар.** `axis(lo,hi)` → 1 · 2 · 2.5 · 5 × 10^k, 0-ээс эхэлнэ,
   3–5 tick. Шошго НЭГ дүрмээр (`tickLabel`): дээд tick < 100,000 бол бүтэн тоо
   («40,000»), түүнээс их бол K/M; аравтын орон алхмаас («0.5M», «250K», «0.25%»).
   Хуучин модель үүсгэгч tick бүрт түүхий утга `v`-г өгнө, `relabel()` дахин шошголно.
5. **X шошгын сийрүүлэлт plot-ын БОДИТ өргөнөөр** (CSS container query): шошго бүрт
   `eh-ch-xw<T>` анги — plot `T`px-ээс нарийн бол нуугдана. Алхам 2-ын зэрэг тул
   нарийн өргөнд үлдэх шошго өргөнд ч үлдэнэ. Эхний ба сүүлийн (дутуу «*») шошго үргэлж.
6. **Легенд plot-ын ДЭЭР**, дээж нь тэмдгийн яг хэв (багана · шугам · тасархай · hollow).
   Тайлбар өгүүлбэр (тэнхлэг тэгээс, дутуу сар) plot-ын доор `.eh-ch-note`.
7. **Дутуу сар hollow цэг** (DG-P), шугамд холбогдохгүй; богино шошго («10-р сар 1–28 ·
   54 · дутуу») легендэд.
8. **Өгөгдөлгүй бол frame зурахгүй** (EMP): frame-ийг `<sc-if value="{{ X.fr.cls }}">`-д
   ороож, оронд нь plot-ын өндөртэй `.eh-ch-empty` хайрцагт нэг мөр тайлбар. Хоосон
   тэнхлэг/сүлжээ зурвал карт 70% хоосон харагдана (layout-audit `card-empty`).
9. **Treemap**-ийн 64px-ээс нарийн хайрцагт шошго нуугдана (container query) — утга нь
   hover tooltip-д; «11…» гэж таслагдсан тоо харуулахгүй.

## Байрлалын дүрэм

- **Богино цуваа (<15 ангилал) ширээний өргөнд ганцаараа бүтэн өргөнийг эзлэхгүй** —
  хос мөрөнд (`class="eh-g-1c eh-row"`, `1fr 1fr` эсвэл `1.5fr 1fr`). Хос нь утга
  нэмэх график байна (жиш. «Сарын үзлэг» ↔ «Тэнцээгүй хувь — сараар»).
- **Урт цуваа (≥15 цэг, 30 хоног) ба газрын зураг** бүтэн өргөнтэй байж болно, `size:'l'`.
- Treemap — HTML хайрцаг (`.eh-tm`, 260px), хувиар байрлана.
- Нэг мөрийн картууд ижил өндөр (UI стандарт ROW).

## Шинэ график нэмэх

```js
// Модель үүсгэгчийн гаралт (w×h, padL/padR/padT/padB, yTicks{y,v,label}, xTicks, bars, dotPts, line)
chart.fr = chFrame(chart, { barFill, line:{stroke,sw}, dotColor, n, size:'m', legend:[…] });

// Эсвэл шууд (plot-ын 0…1000 координат)
const ax = EHChartKit.axis(0, max), y = (v) => 1000 - v / ax.hi * 1000;
x.fr = EHChartKit.frame({ size:'m', n, y: ax.ticks.map((v) => ({ y: y(v), label: EHChartKit.tickLabel(v, ax) })),
  x: […], rects: […{tip}], paths: […], dots: […{tip, hollow}], legend: […] });
```

Темплейт — бусад графикийн FRAME хэсгийг яг хуулна (`class="{{ X.fr.cls }}"
data-eh-chart="{{ X.fr.n }}"`, `.eh-ch-lg` → `.eh-ch-plot` → `svg.eh-ch-svg` → цэг →
утга → X шошго). Модель үүсгэгч функц `EHChartKit`-ийг шууд дуудахгүй (тестүүд
тэднийг тусгаарлан eval хийдэг) — `chFrame` дуудагч талд.

## Үл хамаарал

`width:100%;height:auto` svg зөвхөн харьцаа нь утгатай үед: газрын зураг, зураглал.
Мөрөнд нь `data-ch-ok="шалтгаан"`. Одоогийн жагсаалт: hero-ийн изометрик зураглал,
нүүрийн газрын зураг, урсгалын бөмбөрцөг, аймгийн газрын зураг, нүүрийн t05/i06
(админы preview-тэй хамт шилжүүлэх — дараагийн алхам).
