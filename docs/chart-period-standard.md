# Графикийн хугацааны стандарт

**Зорилго:** хэрэглэгч аль ч диаграмм, жагсаалтыг харахад ЯГ ямар хугацааны
датаг харуулж байгааг ойлгох ёстой. Өмнө нь "Чиглэлээр", "Ачааны төрлөөр",
"Өртөө" зэрэг карт хугацаагаа огт хэлдэггүй байсан (2026-10-19 гомдол).

## 1. Дүрэм

1. **Диаграмм бүр гарчгийн доор хугацааны мөр** харуулна:

   `Хугацаа: 2022-01 — 2026-08 · 44 сар`

   - Эхлэх ба дуусах сар (`YYYY-MM`) — өгөгдөлгүй сар хамаагүй, хүрээ нь
     эхний ба сүүлийн сараас тооцогдоно.
   - Сарын тоо нь хүрээний **бүх** сар (өгөгдөлгүй сар ч тоологдоно), тиймээс
     "44 сар" гэдэг нь 2022-01-ээс 2026-08 хүртэлх календарийн сарын тоо.
2. **Дутуу (одоогийн) сар** байвал мөрөнд нэмнэ:
   `· дутуу сар (2026-10-17 хүртэл)`. Дутуу сарыг бүтэн сар мэт харуулахгүй.
3. **Шүүлт өөрчлөгдөхөд** хугацааны мөр хамт өөрчлөгдөнө (он / сарын интервал).
   Шүүлтийн хүрээнээс гадуурх хугацааг харуулахгүй.
4. **Хугацаа зохиохгүй.** Дата алга бол `Хугацаа: мэдээлэл алга`.
5. **Нэг эх сурвалж.** Текст нь `EHGlossary.periodSpan()` (`js/erthub-glossary.js`)-аас
   гарна; өөр газар хугацааг гараар бүтээхгүй. Хугацааны түлхүүр нь
   загварт `periodKeys` (сарын жагсаалт) ба `partialTo` (дутуу сарын сүүлийн
   өдөр) гэж гарна.
6. **Текст content.json-д.** Орчуулга `<dataset>_an.period_prefix`,
   `period_partial`, `period_through`, `period_none`-д байна (`scope_months`-тай адил).

Жишээ (дутуу сартай, шүүлт бүгд):

```
Хугацаа: 2022-01 — 2026-10 · 58 сар · дутуу сар (2026-10-17 хүртэл)
```

## 2. Хэрэгжилт (dataset бүрт)

| Датасэт | Загвар | Харуулах газар | Төлөв |
|---|---|---|---|
| Ачаа тээвэр (rail freight) | `freightAnalysisModel` → `chartPeriod` | Донут, ачааны төрөл, график, өртөө (4 карт) | ✅ |
| Вагон (rail wagon) | `wagonAnalysisModel` → `chartPeriod` | Донут, төрөл, график, станц | ✅ |
| Зорчигч (rail pax) | `paxAnalysisModel` → `chartPeriod` | Донут, сар, график, маршрут, суваг | ✅ |
| Агаарын тээвэр | `airExtra.airPeriod` ← `SECTORS.air.monthly.periodKeys` (шүүлтийн сарын муж) | «Сараар зорчигч ба нислэг», «Сараар ачааны хэмжээ» | ✅ (сарын 2 график) |
| Агаарын карт (донут ОУ/ОН, улсын жагсаалт, тээвэрлэгчийн зах зээл, ачааны жагсаалт, газрын зураг, treemap) | `airExtra.airPeriod` (ижил муж) | 6 карт, гарчгийн доор | ✅ — шүүлт (он, сар, чиглэл, бүс) бүгд нэг мужаар тооцогдоно |
| Трендийн карт (сарын цуваа, жишээ: «Сарын зорчигч · 2026») | `dsTrendPeriod` ← `SECTORS[k].c1d` + `c1dYear` (бодит бичлэгтэй сарууд) | Тренд муруйн гарчгийн доор; дутуу сар цуваанаас хасагдсан бол «дутуу сар хасагдсан» | ✅ |
| Үзлэг, AI, бусад датасэт | — | — | ⏳ |

⏳ мөрүүдэд хугацааны мөр нэмэхдээ дээрх дүрмийг ЯГ дага: загварт
`periodKeys` + `partialTo`, гарчгийн доор `{{ detail.chartPeriod }}`.

## 3. Шинэ датасэт / график нэмэхэд шалгах

1. Карт бүрийн гарчгийн доор хугацааны мөр байгаа эсэх.
2. Шүүлт (он, сар, интервал) солихоор мөр хамт өөрчлөгдөх эсэх.
3. Дутуу сар байвал "дутуу" гэж тэмдэглэгдсэн эсэх.
4. Датагүй үед "мэдээлэл алга" гэж харагдах эсэх (хугацаа зохиохгүй).
5. content.json-д `period_*` түлхүүр бүртгэгдсэн эсэх (`tests/text-coverage.js`).

## 4. Тест

- `node tests/run.js --only=DG` — DG-P1…DG-P10 (`periodSpan`: хүрээ, сарын тоо, тренд, агаарын муж,
  өгөгдөлгүй сар, дутуу сар, хоосон, орчуулга).
- `node tests/text-coverage.js` — шинэ текст content.json-д бүртгэгдсэн эсэх.
- `node tests/layout-audit.js` — мөр гарч байгаа ч карт давхцахгүй эсэх.
