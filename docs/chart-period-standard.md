# Графикийн хугацааны стандарт

**Зорилго:** хэрэглэгч аль ч диаграмм, жагсаалтыг харахад ЯГ ямар хугацааны
датаг харуулж байгааг ойлгох ёстой. Өмнө нь "Чиглэлээр", "Ачааны төрлөөр",
"Өртөө" зэрэг карт хугацаагаа огт хэлдэггүй байсан (2026-10-19 гомдол).

## 1. Дүрэм

1. **Диаграмм бүр гарчгийн доор хугацааны мөр** харуулна:

   `Хугацаа: 2022-01 — 2026-08 · 44 сар`

   - Эхлэх ба дуусах сар (`YYYY-MM`) — өгөгдөлгүй сар хамаагүй, хүрээ нь
     эхний ба сүүлийн сараас тооцогдоно.
   - Сарын тоо нь хүрээний **бүх** сар (өгөгдөлгүй сар ч тоологдоно), тиймээс
     "44 сар" гэдэг нь 2022-01-ээс 2026-08 хүртэлх календарийн сарын тоо.
2. **Дутуу (одоогийн) сар** байвал мөрөнд нэмнэ:
   `· дутуу сар (2026-10-17 хүртэл)`. Дутуу сарыг бүтэн сар мэт харуулахгүй.
   Хэд хэдэн дутуу сар байвал ТООГ нь хэлнэ: `· 2 дутуу сар (сүүлийнх 2026-10-17 хүртэл)`
   (вагон: эх сурвалжийн цоорхой 2025-12 + одоогийн сар). `partialTo` = СҮҮЛИЙН дутуу сарын огноо.
7. **Нэг хоногийн агшин** (сарын хүрээ биш) — `asOf`: `Хугацаа: 2026-10-19 · сүүлийн бүрэн хоног`
   (вагоны «Салбарын бүтэц» = сүүлийн бүрэн хоногийн станцын задаргаа). Хажуугийн 46 сарын
   картуудтай ижил хугацаа мэт уншигдахаас сэргийлнэ.
8. **Зай:** хугацааны мөр гарчгаас ЯГ 6px доор (`margin-top` = 6 − гарчгийн `margin-bottom`).
3. **Шүүлт өөрчлөгдөхөд** хугацааны мөр хамт өөрчлөгдөнө (он / сарын интервал).
   Шүүлтийн хүрээнээс гадуурх хугацааг харуулахгүй.
4. **Хугацаа зохиохгүй.** Дата алга бол `Хугацаа: мэдээлэл алга`.
5. **Нэг эх сурвалж.** Текст нь `EHGlossary.periodSpan()` (`js/erthub-glossary.js`)-аас
   гарна; өөр газар хугацааг гараар бүтээхгүй. Хугацааны түлхүүр нь
   загварт `periodKeys` (сарын жагсаалт) ба `partialTo` (дутуу сарын сүүлийн
   өдөр) гэж гарна.
6. **Текст content.json-д.** Орчуулга `<dataset>_an.period_prefix`,
   `period_partial`, `period_through`, `period_none`, `period_last`, `period_day`-д байна (`scope_months`-тай адил).

Жишээ (дутуу сартай, шүүлт бүгд):

```
Хугацаа: 2022-01 — 2026-10 · 58 сар · дутуу сар (2026-10-17 хүртэл)
```

**Хоногийн муж (`dayFrom` / `dayTo`).** Сарын хүрээ биш, хоногоор цуваа/тайлан бол
`periodSpan({dayFrom, dayTo})` → `Хугацаа: 2026-10-12 — 2026-10-18 · 7 хоног`
(`chart.period_days`). Урвуу дарааллыг эрэмбэлнэ, эвдэрсэн огноо → «мэдээлэл алга» (DG-P14).

**Чөлөөлөлт (`data-period-exempt="шалтгаан"`).** Хугацааны өгөгдөл биш, эсвэл хугацаа нь
өөр газар хэлэгдсэн дүрс: k04 KPI spark (хугацаа нь картын хөлд, `k04Foot`), «Дата чанарын
үнэлгээ» (оноо). Шалтгаангүй чөлөөлөхгүй.

Цуваагүй трендийн карт («чиг хандлагын цуваа алга») утгатай картын хажууд ЗУРАГДАХГҮЙ —
`showTrendCard` / `data-solo="1"`-ээр утгатай карт мөрийг бүтнээр эзэлнэ (EMP, DG-P13).

Шинэ картад хугацааны мөр нэмэхдээ дээрх дүрмийг ЯГ дага: загварт
`periodKeys` + `partialTo` (эсвэл `dayFrom`/`dayTo`), гарчгийн доор
`<div data-chart-period="1">{{ … }}</div>` — шалгагч энэ атрибутаар таньдаг.

## 3. Шинэ датасэт / график нэмэхэд шалгах

1. Карт бүрийн гарчгийн доор хугацааны мөр байгаа эсэх.
2. Шүүлт (он, сар, интервал) солихоор мөр хамт өөрчлөгдөх эсэх.
3. Дутуу сар байвал "дутуу" гэж тэмдэглэгдсэн эсэх.
4. Датагүй үед "мэдээлэл алга" гэж харагдах эсэх (хугацаа зохиохгүй).
5. content.json-д `period_*` түлхүүр бүртгэгдсэн эсэх (`tests/text-coverage.js`).

## 4. Тест

- `node tests/run.js --only=DG` — DG-P1…DG-P13 (`periodSpan`: хүрээ, сарын тоо, тренд, агаарын муж,
  өгөгдөлгүй сар, дутуу сар, хоосон, орчуулга); DG-P14–P15 хоногийн муж.
- **Бүрдлийн проб** (`tests/lib/period-probe.js`, DG-P16–P18): хуудас бүрийг (нүүр, салбарын
  таб, каталог, датасэт бүр, vehreg …) фикстурын өгөгдөлтэй (`?fx=1`) жинхэнэ хөтчөөр зурж,
  дата тэмдэгтэй svg ба эрэмбийн жагсаалт БҮР картынхаа дотор `[data-chart-period]` мөртэй
  эсэхийг тулгана (DG-P16, одоо 66 карт). Проб тэмдгээс дээш алхахдаа картын хүрээнд
  (border-radius ≥12px + хүрээ/сүүдэр) зогсоно — хөршийн мөрөөр худал ногоон гарахгүй.
  DG-P17 нь утгад тохирсон нэгжийг (хоног / сар), DG-P18 нь үзлэгийн `perDaily` мөрийг
  хассан хуулбар дээр проб өөрөө унахыг баталгаажуулна.
- `node tests/text-coverage.js` — шинэ текст content.json-д бүртгэгдсэн эсэх.
- `node tests/layout-audit.js` — мөр гарч байгаа ч карт давхцахгүй эсэх.
